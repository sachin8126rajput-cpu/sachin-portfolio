# Sachin Kumar — Professional Portfolio

A polished, responsive personal portfolio with deep charcoal surfaces, muted lavender, mint and blue accents, subtle grain, soft glows, animated reveal effects, and a responsive navigation.

## Included
- `index.html` — personal portfolio content
- `style.css` — color grading, responsive layout and visual effects
- `script.js` — mobile navigation, scroll reveal, contact mailto flow
- `assets/sachin-profile.jpg` — profile image
- `assets/Sachin_Kumar_Resume.pdf` — uploaded resume

## Before publishing
- The contact form opens the visitor's default email application with the message prefilled. It does not silently send or store messages. For a server-backed form, connect a form provider such as FormSubmit or Formspree and configure/verify it.
- Add your actual GitHub profile URL and verified project repository/demo URLs when available. No fabricated project URLs are included.
- Review your resume for personal details you want to make public before publishing it.

## Run locally
Open `index.html` in a modern browser. Google Fonts requires an internet connection; fallback fonts are provided.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open repository **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. After GitHub finishes publishing, open the URL shown in Pages settings.
